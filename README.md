# NEXORA - Digital Agency Website

A modern and responsive digital agency landing page built using HTML5 and CSS3.

## Project Overview

NEXORA is a fictional digital agency website designed to showcase creative services, featured projects, and contact information through a modern dark-themed interface.

## Features

- Modern and clean UI design
- Responsive layout
- Navigation links between sections
- Services showcase
- Featured projects section
- Contact section
- Smooth scrolling
- CSS hover effects

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

1. Download or clone the repository.
2. Open the project folder.
